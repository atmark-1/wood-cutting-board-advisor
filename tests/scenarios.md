# 测试场景（输入 → 预期输出）

贡献者改数据后，对照本表跑一遍典型场景，确认推荐逻辑未被破坏。预期输出为「推荐材质 + 关键理由」，数值以 materials.csv 为准（随数据更新可能微调）。

## 场景 1：切配为主 + 偶尔剁 + 浙江（典型南方家庭）
- 输入：主要切家常菜配菜，偶尔剁排骨/整鸡/腊猪腿，护刀不在意，家在浙江
- 预期：首选**乌檀厚板**（切配 4.0 舒服、剁骨 3.8 偶尔够、含油防霉浙江可用、可得性满屏）；备选**相思木**（剁骨 4.3 更强）；防霉控**绿柄桑/非洲柚木**（防霉 4.0 三线全过）
- 必排除：菠萝格（可得性=几乎无，必须走规则 9 降级）、银杏（剁骨 1.5 不能剁腊猪腿）、铁木/重蚁木（切配 2.5 劝退）

## 场景 2：预算 150、南方、不剁骨
- 输入：预算 150，浙江，只切菜切肉不剁骨
- 预期：**乌檀厚板**（150-300 内，切配好）；或**银杏木**（护刀、京东有榜好买，但提示软不可剁）

## 场景 3：北方干燥 + 常剁骨
- 输入：北京，常剁排骨大骨，预算 300
- 预期：**柞木/枣木**（剁骨 4.3-4.5、北方防裂好）或**皂角木**（鲁豫可买）；提示枣木认老料防染色假货

## 场景 4：预算 >500 懒人
- 输入：预算充足，不想保养，南方
- 预期：**真缅甸柚木**（含油免养）——必须提示"市面低价柚木多为冒充，38cm 整板 800+ 才算真，非行家慎追"；或接受 300-500 的"柚木"=非洲柚木

## 场景 5：护刀党 + 果蔬辅食
- 输入：在意不伤刀，主要切果蔬，不剁骨
- 预期：**梨木**（中硬回弹）或**银杏/桧木**（软木辅食板）；提示梨木品种混杂认品牌、银杏痕内藏渣勤刷

## 场景 6：生熟分板
- 输入：想买两块，生熟分开
- 预期：生食/剁骨→**乌檀厚板或相思木**（硬木）；熟食/果蔬→**梨木或银杏**（护刀软木）

## 场景 7：红线一票否决
- 输入：问樟木/橡胶木/竹板菜板能不能买
- 预期：樟木（樟脑油）排除、橡胶木（脲醛胶）不推荐主力、竹板（胶拼）排除——直接说"不买"，不解释成分歧

## 场景 8：南方 + 防霉强迫症
- 输入：浙江，最怕发霉，预算 400
- 预期：**绿柄桑/非洲柚木**（防霉 4.0 三线全过，搜"柚木 300-500"）或**柚木**（防霉 4.5，提示剁骨 3.8 偏弱、真货价高）
