# 实木菜板选购顾问（Wood Cutting Board Advisor）

一个可直接导入 [WorkBuddy](https://www.workbuddy.cn) 的选购顾问技能：基于 **25 种实木材质的硬指标数据源**（含电商可得性）和 **9 条决策规则**，按你的厨房场景（切配 / 剁骨 / 地域 / 预算 / 护刀偏好）直接给出顾问式推荐——**不做综合打分、不排名、不分等级**。

> ⚠ 免责声明：本仓库仅提供木材学知识参考，**不涉及任何交易引导**。铁木（蚬木）为国家二级保护植物，请通过合法渠道购买，本仓库不提供购买渠道信息。数据为经验估值（非实验室实测），请理性参考。

## 快速开始（选你的身份）

- **WorkBuddy 用户** → 看 [安装](#安装)，把目录放进 `~/.workbuddy/skills/`，新会话问"菜板怎么选"即自动生效
- **想复制去问 ChatGPT/Claude/Kimi 等任意 AI** → 复制 [`references/ai-pack.txt`](references/ai-pack.txt) 的**整段内容**发给它即可（内含顾问指令 + 25 材质数据 + 红线 + 规则，无需再带其他文件；聊天 AI 打不开网页链接，只能吃文本）
- **想读数据 / 提 PR** → 看 [`references/materials.md`](references/materials.md)（人类可读表）+ [`CONTRIBUTING.md`](CONTRIBUTING.md)

## 它解决什么

- **短视频/电商只推"好卖"的材，不推行家材**：乌檀、相思、橡胶木到处是广告，菠萝格、绿柄桑、皂角木这些"行家材"反而没人推。本技能按材质真实特性推荐，不按销量。
- **市售水太深**：市面低价"柚木"多为冒充（非洲柚木/泰柚人工林/花梨染色）、乌檀是商业统称（非单一树种）、拼接板有脲醛胶甲醛风险——内置 7 条避坑红线，先排除再推荐。
- **怕买不到/踩雷**：每个材质都标注**电商可得性**（满屏/多/有/少/几乎无，2026-08 实证）——"几乎无"的材质（如菠萝格）推荐前自动降级，不会让你白搜；收货验货见 [`references/buying-checklist.md`](references/buying-checklist.md)。

## 安装

1. 下载 zip 或 `git clone` 本仓库
2. 解压后把 `wood-cutting-board-advisor/` 整个目录放入：

   - 或项目级：`{项目}/.workbuddy/skills/`
3. 重启会话即生效

## 使用示例

触发词：菜板/砧板/切菜板怎么选、XX木菜板好不好、预算X买什么板、南方/剁骨/护刀/生熟分板怎么挑

> 用户：我主要切家常菜，偶尔剁排骨和整只腊猪腿，家在浙江，刀不贵。
>
> 顾问：**乌檀厚板（3cm+）**——满屏买得到，切配 4.0 舒服、剁骨 3.8 偶尔够用、含油防霉浙江可用，150-300。想剁骨更放心选**相思木**（剁骨 4.3，认食品级胶）；防霉强迫症选**绿柄桑/非洲柚木**（防霉 4.0 三线全过）。不推荐菠萝格（可得性=几乎无，买不到）、银杏（不能剁腊猪腿）、铁木/重蚁木（切配 2.5 劝退）。

## 决策规则（9 条）

1. 不做综合打分、不排名、不分等级——直接按用户场景匹配材质
2. 切配为主 → 优先切配手感≥3.8；切配≤3.0（铁木/重蚁木/枣木）除非明确主要剁骨，否则劝退
3. 南方潮湿/梅雨 → 优先防霉≥4.0
4. 常剁硬物（排骨/腊猪腿）→ 优先剁骨≥4.2，选厚板 3.5-4cm+，提示垫防滑垫
5. 在意护刀 → 优先中硬/软木（梨木/樱桃木/银杏/桧木）
6. 预算：≤200 → 乌檀厚板/柞木/绿柄桑；200-500 → 相思木/柚木；>500 → 真缅甸柚木/胡桃木
7. 每次推荐必须引用数据表的具体数字与推荐厚度
8. 先查避坑红线，红线材质直接排除或警告
9. 可得性 fallback：先查 `references/materials.csv` 的「电商可得性」列——「几乎无/少」的材质先降级（乌檀厚板→相思木→大牌拼接板），别让用户买不到

## 数据说明

- 全部为**经验估值**（非实验室实测），Janka 为文献近似，价格按 ~38cm 整木无胶行情估算
- 数据来自 16 版迭代沉淀（v1-v16），经多轮独立评审与脚本验算修正
- **维护**：市售形态变化时只改 `references/materials.csv`（用 `export_skill_csv.py` 同步生成 materials.md），规则与 Prompt 不用动（数据源与使用逻辑解耦）
