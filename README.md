# 实木菜板选购顾问（Wood Cutting Board Advisor）

一个可直接导入 [WorkBuddy](https://www.workbuddy.cn) 的选购顾问技能：基于 **25 种实木材质的硬指标数据源**和 **8 条决策规则**，按你的厨房场景（切配 / 剁骨 / 地域 / 预算 / 护刀偏好）直接给出顾问式推荐——**不做综合打分、不排名、不分等级**。

## 它解决什么

- **短视频/电商只推"好卖"的材，不推行家材**：乌檀、相思、橡胶木到处是广告，菠萝格、绿柄桑、皂角木这些"行家材"反而没人推。本技能按材质真实特性推荐，不按销量。
- **市售水太深**：真缅甸柚木 90% 是冒充（非洲柚木/泰柚人工林/花梨染色）、乌檀是商业统称（非单一树种）、拼接板有脲醛胶甲醛风险——内置 7 条避坑红线，先排除再推荐。
- **怕买不到/踩雷**：附市售可得性速查（菠萝格=印茄木、绿柄桑=非洲柚木，搜对市场名才买得到）+ 万能验货 4 条（看截面/闻味道/问胶种/厚度优先）。

## 安装

1. 下载 zip 或 `git clone` 本仓库
2. 解压后把 `wood-cutting-board-advisor/` 整个目录放入：
   - 用户级（本机所有项目可用）：`~/.workbuddy/skills/`
   - 或项目级：`{项目}/.workbuddy/skills/`
3. 重启会话即生效

## 使用示例

触发词：菜板/砧板/切菜板怎么选、XX木菜板好不好、预算X买什么板、南方/剁骨/护刀/生熟分板怎么挑

> 用户：我主要切家常菜，偶尔剁排骨和整只腊猪腿，家在浙江，刀不贵。
>
> 顾问：**菠萝格厚板**——切配 3.6（切菜不硌手）、剁骨 4.4（腊猪腿扛得住）、防霉 4.5（浙江梅雨顶级）、结构 4.5、工艺整木无胶，选 3.5-4cm 厚款，价 200-500。省钱备选绿柄桑（150-350，三线全过）；皂角木防霉 3.8 差一线需勤干；柚木剁骨 3.8 对硬物偏弱；铁木/重蚁木切配 2.5 劝退。

```

└── references/
    ├── materials.csv           # 25材质 × 15字段硬指标（切配/剁骨/防霉/结构/重量/价格上下限/推荐厚度/工艺安全/核心备注）
    └── prompt_for_other_ai.md  # 可复制去问任意 AI 的顾问 Prompt（数据源与使用逻辑解耦）
```

## 决策规则（8 条）

1. 不做综合打分、不排名、不分等级——直接按用户场景匹配材质
2. 切配为主 → 优先切配手感≥3.8；切配≤3.0（铁木/重蚁木/枣木）除非明确主要剁骨，否则劝退
3. 南方潮湿/梅雨 → 优先防霉≥4.0
4. 常剁硬物（排骨/腊猪腿）→ 优先剁骨≥4.2，选厚板 3.5-4cm+，提示垫防滑垫
5. 在意护刀 → 优先中硬/软木（梨木/樱桃木/银杏/桧木）
6. 预算：≤200 → 柞木/白橡/皂角木/绿柄桑；200-500 → 菠萝格（甜点区）；>500 → 真缅甸柚木/胡桃木
7. 每次推荐必须引用数据表的具体数字与推荐厚度
8. 先查避坑红线，红线材质直接排除或警告

## 数据说明

- 全部为**经验估值**（非实验室实测），Janka 为文献近似，价格按 ~38cm 整木无胶行情估算
- 数据来自 16 版迭代沉淀（v1-v16），经多轮独立评审与脚本验算修正（公式、等级、口径均逐项核对）
- **维护**：市售形态变化时只改 `references/materials.csv` 与 SKILL.md 红线段，规则与 Prompt 不用动（数据源与使用逻辑解耦）
